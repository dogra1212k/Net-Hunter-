# Security / Responsible Use

This repository is for learning Linux, Termux and Kali NetHunter; systems you own; CTFs; deliberately vulnerable labs; and security assessments where you have explicit authorization.

Do not use the material to access accounts, devices, networks or data without permission.

Security tools can cause outages, lockouts, data loss, legal problems, and deeply awkward conversations with people wearing lanyards.

Prefer isolated labs and backups. For real assessments, define scope, allowed techniques, timing, data-handling rules and emergency contacts before testing.
