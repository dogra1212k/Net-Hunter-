# Google Play Store Listing Draft

## App name

Net Hunter Guide

## Short description

Offline Termux, Kali NetHunter and Linux learning guide with lessons, labs and quizzes.

## Full description

Net Hunter Guide is an offline learning companion for Android users who want a structured introduction to Termux, Kali Linux, NetHunter, Linux commands, networking, web basics, forensics concepts, troubleshooting and safe practice labs.

### Learn step by step

- 13 offline lessons
- Linux and command-line basics
- Networking and web fundamentals
- Kali tool categories and notes
- Installation and troubleshooting guidance
- Safe practice labs
- Command reference
- Learning roadmap

### Track your learning

- Mark lessons complete
- Save favorites
- Continue your last lesson
- Remember reading position
- Filter incomplete lessons
- Add personal notes
- Adjust lesson text size
- Backup and restore local progress

### Practice

Use the built-in offline quiz to test basic Linux, networking, HTTP, socket and hashing knowledge. Quiz results include explanations, last score and best score.

### Offline by design

Core lessons open inside the app and do not require a browser. The current app does not include ads, analytics, login, cloud sync or remote tracking.

### Responsible use

Security-related commands and tools should only be used on your own devices, localhost, personal labs, or systems where you have explicit authorization.

Net Hunter Guide is an educational reference. It is not a remote-control, exploitation or unauthorized-access tool.
