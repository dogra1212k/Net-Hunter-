# Tool Lessons

इन lessons को क्रम से पढ़ें। हर lesson में **where to run**, **install**, **why**, **basic commands**, **output**, और **safe practice** दिया गया है.

1. [Nmap](nmap.md) — ports/services समझना
2. [DNS: dig + whois](dns-recon.md) — DNS और public registration data
3. [curl + WhatWeb](web-basics.md) — HTTP और web technology basics
4. [tcpdump + Wireshark](packet-analysis.md) — packets और protocols
5. [Forensics basics](forensics-basics.md) — file, strings, hashes, metadata, binwalk
6. [John the Ripper basics](john-basics.md) — अपने lab hashes की password auditing

## Rule

पहले `--help` / `man`, फिर छोटा authorized lab, फिर result की explanation. किसी random IP/domain पर commands चलाना “practice” नहीं कहलाता; वह बस किसी और की problem बन सकती है.
