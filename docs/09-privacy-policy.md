# Privacy Policy — Net Hunter Guide

**Effective date:** October 3, 2026

Net Hunter Guide is designed as an offline learning app for Termux, Kali Linux, NetHunter, Linux, networking, web basics, forensics basics, and safe practice labs.

## Data collection

The app does not currently collect, transmit, sell, or share personal data.

The app does not currently include:

- account sign-in;
- analytics SDKs;
- advertising SDKs;
- remote tracking;
- cloud synchronization;
- background network access;
- location access;
- contacts access;
- camera access;
- microphone access.

## Data stored on the device

The app may store the following locally on the user's device:

- lesson completion status;
- favorite lessons;
- personal lesson notes;
- last-opened lesson;
- per-lesson reading position;
- preferred lesson text size;
- quiz scores.

This data is stored locally using Android SharedPreferences.

## Backup and restore

Android automatic/cloud backup is disabled for this app.

Users can explicitly export their local learning state to a JSON backup file and later import that file. The user chooses where that backup file is saved and which file is restored.

Because exported backup files may contain personal lesson notes, users should store and share those files carefully.

## Sharing

The app can use Android's standard share sheet when the user chooses **Share lesson**. Personal notes are not included in shared lesson text.

## Network behavior

The current app does not declare Android network permissions and is intended to work offline.

## Changes

If future versions add analytics, accounts, cloud sync, ads, or other data-processing features, this privacy policy and the Google Play Data safety form must be updated before release.
