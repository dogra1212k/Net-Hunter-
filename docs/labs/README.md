# Hands-on Practice Labs

These labs are designed for **your own phone, localhost, files, or an explicitly authorized lab**.

## Order

1. [Linux & Shell Basics](01-linux-shell.md)
2. [Networking Basics](02-network-basics.md)

- what each command does

Do not run scanning, password auditing, or traffic capture against systems you do not own or have permission to test.
