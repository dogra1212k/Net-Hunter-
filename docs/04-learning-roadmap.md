# 4. Learning Roadmap

## Stage 1: Terminal
Learn:
- files/directories
- permissions
- processes
- pipes/redirection
- package management
- Git

Practice: create directories, edit files, search text and inspect help pages.

## Stage 2: Networking
Learn:
- IPv4/IPv6
- MAC addresses
- DNS
- TCP vs UDP
- ports
- routing
- HTTP/HTTPS

Commands:

```bash
ip addr
ip route
ss -tuln
ping -c 4 127.0.0.1
dig example.com
```

## Stage 3: Python and shell
Write small scripts that parse your own files, make requests to test services and automate repetitive administration.

## Stage 4: Recon and service identification
Use an isolated lab or machines you own. Learn what information tools return and verify it manually.

## Stage 5: Web security
Study HTTP, authentication, sessions, access control, input validation and common vulnerability classes. Practice with intentionally vulnerable training apps.

## Stage 6: Traffic analysis
Capture your own lab traffic and learn Ethernet/IP/TCP/DNS/HTTP packet structure.

## Stage 7: Forensics
Practice metadata, hashes, file signatures, timelines and evidence handling.

## Stage 8: Reporting
For every exercise record:
1. Scope
2. Command used
3. Expected result
4. Actual result
5. Evidence
6. Explanation
7. Remediation

A security tester who cannot explain a finding is basically a very expensive notification generator.
